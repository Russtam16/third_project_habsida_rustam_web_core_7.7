## Что сделано:
- Модальное окно закреплено поверх страницы с помощью `position: fixed`.
- Содержимое аккуратно отцентрировано через Flexbox.
- Настроена полупрозрачная подложка (`.modal-backdrop`) с затемнением фона.
- Строго соблюдена иерархия слоев (`z-index: 1000` для модалки, `1` для подложки и `2` для карточки).
- Стили адаптированы для мобильных устройств.
